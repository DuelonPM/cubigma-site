Privacy Policy

CUBIGMA mobile game (iPhone, Android) · effective October 13, 2026

In short

  • The game has no sign-up and no accounts. We never ask for your name, email, phone number, age or date of birth.
  • We do not use the advertising identifier (IDFA on iPhone, Advertising ID on Android), do not track you across other apps or websites, show no ads and never sell data.
  • The game contains no third-party analytics, advertising or social SDKs.
  • To run daily rewards, the leaderboard and game statistics, the game stores an anonymous installation code and game data on our server.

What is stored on the server

On first launch the game creates a random installation code and a secret key for it. They are not linked to your name, Apple ID, Google account or device. Stored with this code:

  • Daily check-ins and rewards: check-in days (UTC), streak day, rewards claimed and daily hints received.
  • Leaderboard: puzzle results and points, current league, chosen avatar and a public number. On the leaderboard you appear only as “Player 1234”, never by name.
  • Purchases: which packs are unlocked (for example, the full version). Payments are handled by Apple (App Store) or Google (Google Play); we never receive card or payment details.
  • Gameplay statistics: events such as “puzzle started”, “puzzle solved”, “hint used”, “shop opened”, the selected mode (Kid or Adult), play time, game version and platform. Events contain no names and no free text.

Like any internet service, the server technically receives your IP address when the game connects. We do not store it with game data and do not use it to determine your location.

What stays on your phone only

Your progress, the puzzle in progress, sound and vibration settings, the selected mode and the name you type in your profile. That name is never sent to the server and never shown on the leaderboard.

Why we use this data

  • to count daily check-ins and give rewards;
  • to calculate points and show the leaderboard;
  • to remember your purchases;
  • to see which puzzles are too hard, where players get stuck, and to improve the game.

We do not use data for advertising and do not share it with ad networks or data brokers.

Who processes the data

The game server runs on Convex (Convex, Inc.), in a data center in the United States. Convex stores data on our behalf and does not use it for its own purposes. Purchases are processed by Apple and Google under their own terms.

Security

All data is sent only over an encrypted connection (HTTPS). The installation’s secret key is stored on the server as a hash. Only the game’s developer can access the data.

Kid mode

The game has a mode for children. We do not ask for age and do not knowingly collect personal information from children. Kid mode collects the same anonymous gameplay statistics as Adult mode, with no name, contact details or location. The game has no ads, no advertising identifiers and no third-party SDKs, in line with Apple’s rules for kids apps and the Google Play Families policy. A parent can ask us to delete an installation’s data at any time (see below).

Support emails

If you contact us via “Write to us”, your mail app pre-fills the game version, your player code, phone model and system version (iOS or Android). You see the whole message and can remove any line before sending. We use your email address and message only to reply.

How long data is kept

Installation data is kept while you play. If an installation has not checked in for 24 months, its data is deleted. Support emails are kept only as long as needed to answer.

Deletion and your rights

The game has no accounts, so there is no account to delete. Deleting the game from your phone (or clearing the app’s data on Android) wipes all local data and the installation code: after reinstalling, the game starts fresh and the old server data is no longer linked to anything. To have it deleted right away, or to ask what we store, email duelon.pm@gmail.com with the player code from Settings. We will handle the request within 30 days.

Changes

If we change this policy, the new version will appear on this page with a new date. We will announce significant changes in the game.
